## 3. 변경
### 3-1. O-003
- `OnboardingAwareSuccessHandler`: `request.getRemoteAddr()` 를 그대로 기록. 운영에서 항상 null 이던 XFF 읽기와 `LoginLogService.resolveClientIp` 삭제, 틀린 주석("framework 는 getRemoteAddr 를 안 바꾼다") 교체.
- 앱 변경은 **동작이 같다**(운영에서 XFF 분기는 원래 안 탔다). 위조 차단은 nginx 덮어쓰기가 한다 → 배포 순서와 무관.
- `infra/nginx/account.kyuhyeong.com.conf.example`: `X-Forwarded-For $remote_addr` + 이유 주석.
- 테스트: `OnboardingAwareSuccessHandlerTest` 4건 — 실제 `ForwardedHeaderFilter` 를 거친 뒤 핸들러 호출. **구현 전 코드에서 먼저 실행해 4건 통과 확인**(현재 동작 고정: 덧붙인 XFF 면 위조값 `1.2.3.4` 가 기록됨 = 재현).
- `LoginLogServiceTest` 에서 resolveClientIp 3건 삭제(허가) — 대체는 위 테스트.

### 3-2. O-004 (스키마 변경 없음)
- `InviteCodeService`: `VALID_FOR = 3일` 로 발급, `listActive` 에서 `isValid(now)` 로 만료 제외, `revoke(householdId, id)` 추가.
- `InviteCodeRepository.findByIdAndHouseholdId` — `InviteCode` 는 `@Filter` 미적용이라 가구 조건을 쿼리에 직접 건다(`findById` 금지).
- `WebAdminController`: `POST /web/admin/invite/{id}/revoke` — 성공 flash `message`, 남의 코드면 flash `error`. 경로는 기존 `/web/admin/** hasRole("OWNER")` 아래.
- `admin/users.html`: 만료일(`만료 MM-dd HH:mm` / `무기한`) 표시(발급일 대신), 취소 버튼(`confirm()` — 기존 삭제 버튼과 같은 패턴), 안내 문구에 "3일".

### 3-3. O-005
- `account-api/build.gradle.kts` jjwt 3줄 + 주석 삭제. `runtimeClasspath` 에 `jsonwebtoken` 0건.
